# Пушка и мишени

Готовая учебная сцена для **Unity 6000.3.27f1 (Unity 6.3)**, URP и нового Input System. Проект расположен в `/home/jaba/dev/Gun_And_Targets`.

## Запуск

Открыть проект в Unity и сцену **`Assets/Scenes/CannonRange.unity`**, нажать **Play**. Она записана первой и включённой в Build Settings. Все ссылки, материалы, коллайдеры, Prefab и HUD уже сохранены. Исходная `SampleScene.unity` сохранена.

- **W/A/S/D** — движение по X/Z.
- **Q/E** — поворот вокруг Y.
- **Space** — выстрел, 35 м/с.
- **↑/↓** — дополнительная регулировка угла ствола (5–65°).

## Реализация

`CannonController` один раз выбирает массу 2–6 кг и радиус 0.1–0.2 м следующего снаряда. До выстрела они хранятся в `NextMass`/`NextRadius`, отображаются на HUD и используются прогнозом. `Fire` передаёт их в `QuadraticDrag.SetPhysicalParams`, только затем выбирает следующую пару. Диапазоны и физические параметры доступны в Inspector.

`QuadraticDrag` вычисляет `-0.5 * rho * Cd * PI * r² * |v-wind| * (v-wind)`, где по умолчанию rho=1.225, Cd=0.47. В FixedUpdate сила прикладывается через `AddForce(..., ForceMode.Force)`. Используется Unity 6 `linearVelocity`, `linearDamping=0`, гравитация включена. Снаряд удаляется через 15 с. Коллайдер имеет локальный радиус 0.5 и масштаб 2r — без двойного масштабирования.

`TrajectoryRenderer` использует ту же функцию силы, массу, радиус, скорость, ветер и `Time.fixedDeltaTime=0.02`. На каждом шаге сначала обновляется скорость, затем позиция. До 400 шагов; SphereCast заканчивает линию в позиции центра при первом контакте. Слои Cannon и Projectile исключены из прогноза, триггеры игнорируются. Попадание в движущуюся мишень не предсказывает её будущее движение: линия отражает физические препятствия в их текущем положении. Допуск проверки падения без мишеней — 1 м.

`TargetSpawner` создаёт сферы на высоте 8 м примерно в 40 м от исходной позиции пушки. Масса 1–5 кг, радиус 0.4–1 м, горизонтальная скорость 2–5 м/с, без гравитации и damping. Не более четырёх одновременно; интервал 2.5 с, lifetime 10 с. Значения настраиваются. `Target` засчитывает только столкновение с `QuadraticDrag`, не более одного раза на мишень, и окрашивает её в зелёный. `CannonHud` показывает параметры следующего ядра, выстрелы, попадания и управление.

## Воспроизводимость

`Assets/Editor/CannonSceneBuilder.cs` строит сцену и Prefab через Editor API. Меню **Cannon → Build demonstration scene** пересобирает демонстрацию; при обычном запуске это не требуется. Пересборка заменяет только генерируемую сцену и её Prefab/материалы; не используйте её для сохранения ручных изменений демонстрации.

Автоматизация выполнялась официальным Unity CLI и подключённым `com.unity.pipeline` 0.9.0-exp.1. CLI 1.0.0-beta.14. Интерактивная авторизация не понадобилась. Buildin-ссылки не удалось прочитать, реализация следует подробному заданию пользователя.

Тесты: `Assets/Tests/PlayMode/CannonAcceptanceTests.cs`. Запуск из Unity Test Runner, вкладка PlayMode, либо через подключённый Editor:

```bash
unity command test run --caller plugin --skill unity-cli -- --mode playmode --filter CannonAcceptanceTests --async_tests true
unity command test status --caller plugin --skill unity-cli --format json
```

Тесты проверяют ввод настоящих событий Input System, движение и поворот, начало линии у дула, пять полётов Rigidbody до столкновения, соответствие параметров, физику/лимит/движение/lifetime мишеней и однократный подсчёт попаданий. Численные результаты — `Reports/PhysicsFlights.md`; итог запуска — `Reports/AcceptanceResults.json`. Сценарий защиты — `DEFENSE.md`.

Шрифт Noto Sans включён локально с лицензией OFL в `Assets/Fonts/OFL.txt`. Внешние модели и платные ассеты не используются.
